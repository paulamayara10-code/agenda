
# Agenda Departamental

## Como usar

1. Coloque o arquivo `Agenda.xlsx` na mesma pasta do `app.py`.
2. Instale as bibliotecas:

```bash
pip install -r requirements.txt
```

3. Rode o app:

```bash
streamlit run app.py
```

## Estrutura esperada do Excel

Abas:
- Usuarios
- Tarefas
- Projetos
- Historico
- Calendario
- Configuracoes
