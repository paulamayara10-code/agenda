# Agenda Operacional V20 — Rotina Diária

Esta versão troca a lógica do sistema:

- Rotinas: cadastro mestre, não some.
- Tarefas do Dia: checklist gerado por data.
- Pendências anteriores: execuções passadas não concluídas.
- Projetos: separados da rotina diária.

## Uso

1. Coloque Agenda.xlsx na pasta, se quiser migrar as rotinas iniciais.
2. Rode: `streamlit run app.py`
3. No Painel do Dia, clique em `Gerar/atualizar checklist do dia`.
