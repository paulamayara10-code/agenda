# FIRST OPS 3.0

Operational Control Center.

1. Rode `streamlit run app.py`
2. Acesse **Migração**
3. Clique em **IMPORTAR BACKUP PARA O FIRST OPS**
4. Vá em **Home** e gere o checklist do dia.
